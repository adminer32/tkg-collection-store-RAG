# 新票、旧票与邮戳

顾客常问「盖过戳的票还值钱吗」。答案取决于收集目标。本文说明销戳类型，以及店内旧票应当如何理解。

## 实销与盖销

实销（postal cancel）来自真实交寄，戳记可能偏、糊、压到齿孔。盖销（cancelled to order，CTO）是邮政或经销渠道为收藏市场盖的戳，常端正地盖在一角，背胶还在。欧洲 1950–1980 民用纪念票里，实销很常见；某些东欧和海外地区 CTO 更多。本店欧洲组按旧票/中上品零售，不逐枚鉴定是否 CTO。

## 日戳、机戳与纪念戳

圆形日戳含局名与日期，是旧票最典型的痕迹。波浪机戳、喷墨戳可能留下条纹。纪念戳图案强，专题爱好者会特意收集。戳记清晰且不破坏主图中心，通常比一团墨更受欢迎。

## 新票的保存要点

新票怕热、怕潮、怕手油。应用护票袋直立存放，避免相册塑料与背胶长期粘连。中国南方梅雨季尤其容易出斑。本店若无「新票」字样，不要按全新原胶来预期欧洲散票。

## 装饰性使用

旧票作信封装饰时，选择戳记稳、颜色不掉的票。深色戳遇水可能晕染。不要把旧票贴在现行邮票之上。代寄服务使用的有效邮资票由店铺按中国邮政资费另贴。
