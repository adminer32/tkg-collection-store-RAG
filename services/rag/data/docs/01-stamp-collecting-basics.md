# 集邮入门

本文面向高木桑收藏品店的顾客，说明邮票收藏的基本词汇与入门路径。内容为通用集邮知识整理，不是某一次网上抓取的原文，也不构成投资建议。

## 邮票是什么

邮票最初是预付邮资的凭证。一枚邮票通常包含：发行邮政、面值、图案、齿孔、背胶，以及可能的水印或荧光防伪。进入收藏领域后，邮票同时是历史纸片、印刷品和专题素材。店内欧洲复古散票、限量珍藏套票，都按「可收藏的纸本邮品」出售，不承诺升值。

## 新票与旧票

新票（mint）指未经实寄、齿孔完整的邮票。带原胶、无贴痕的常称 MNH（mint never hinged）。旧票（used）经过实寄或盖销，票面留有邮戳。两者没有绝对高低：专题集邮常收旧票上的戳记与图案；传统集邮更看重新票品相。本店欧洲散票以中上品旧票为主，可能带销戳。

## 套票、散票与小型张

套票是同一主题一次发行的若干枚，常按设计成组收藏。散票是拆开后的单枚或混杂整理，价格更低，适合入门和装饰信封。小型张、小全张是带边纸的小型印刷单元，边纸上的厂铭、序号也有人收集。店内「欧洲复古邮票散票」属于散票整理组，不是完整新年号套票。

## 面值与收藏价值

面值只表示发行时的邮资，不等于今天的市场价。普通票发行量大，多数接近或低于面值；纪念票、限量票、错体票才可能明显高于面值。本店标价是零售整理价，覆盖挑选、品相说明与包装，不是目录报价，也不保证未来成交价。

## 入门建议

先选一个范围：国家（如德、法、意）、年代（如 1950–1980）、或主题（花卉、交通、建筑）。用插册或定位册按发行或主题排列，避免把不同湿度的票混在密封袋里。对店内商品有疑问，可用商店助手检索「品相」「销戳」「散票」等词，对照本文与商品摘要。
