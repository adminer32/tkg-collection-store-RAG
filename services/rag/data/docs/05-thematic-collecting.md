# 专题集邮

专题集邮按主题收集图案，而不是按一个国家的编年。花卉、交通、建筑、动物、体育都是常见专题。店内限量珍藏邮票当前可含花卉与交通混合组，欧洲散票里的风景与人物也可拆进专题。

## 专题怎么开始

先写一句范围：例如「欧洲火车」或「亚洲花卉」。只收主图明确属于该主题的票，避免把含一点叶子的票都算花卉。用定位册按亚主题分页：车辆类型、花名、国家。每页用护票袋，票下铅笔注国家与大约年份即可，不必一开始就上斯科特或 Michel 编号。

## 图案、边纸与戳记

专题不只收票图。销戳上的火车邮局、纪念戳上的花卉展，也能当素材。边纸厂铭、过桥连票对进阶者有意义，入门散票组很少保证连票。本店散票以单枚为主。

## 和编年集邮的差别

编年集邮追求某国某段时间尽量齐全，缺套会难受。专题允许跨国家，心理负担小，也更适合把票用在信件、明信片装饰。缺点是市场上「热门专题」仿品和廉价胶印复制更多，买低价大套花票时要看齿孔与纸质。

## 店内可对应的商品

欧洲复古散票：适合建筑、旅游、人物入门。限量珍藏邮票：适合已经有基础、想补花卉或交通的人。明信片与礼盒：不是邮票专题，但同一主题的纸本可以一起陈列。商店助手可问「交通邮票」「花卉」「风景票」。
